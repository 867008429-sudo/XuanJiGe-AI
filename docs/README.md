# 文档索引

这个目录存放项目的长文档、规划记录和截图。GitHub 根目录只保留运行入口与核心代码，内部推进材料统一放在这里。

## 主要文档

| 路径 | 内容 |
|------|------|
| `technical-overview.md` | 原 README 长文版：架构、prompt、部署、API、路线图 |
| `plans/agent-plan.md` | Agent 化总体推进计划 |
| `plans/persona-plan.md` | 道长人格、香火计量和前端选择条设计 |
| `planning/task_plan.md` | 当前任务阶段表 |
| `planning/findings.md` | 关键发现与决策记录 |
| `progress/` | 分日进度日志与合并进度 |
| `screenshot-agent-chat.png` | README 主图：命盘 Agent 追问界面 |
| `screenshot-*.png` | 历史展示截图 |

## 目录约定

- 对外入口写在根目录 `README.md`。
- 技术细节、阶段计划、历史进度写入 `docs/`。
- 可运行实验代码放在 `spikes/`，实验总结放在 `spikes/README.md`。
- 密钥、数据库、本地截图和临时产物不入库。
